# MuJoCo 具体数据案例实施计划

> **For agentic workers:** 使用 subagent-driven-development 的任务分工与独立复核流程；用户已要求将真实数据与学习路径结合具体案例讲清楚。

**Goal:** 让初学者从明确入口打开实验，并把一个真实记录时刻的画面、动作、状态、传感器和下一状态逐项对应。

**Architecture:** 在现有仿真器专题增加 MDX 案例页。独立 Astro 组件读取固定 episode 的 JSON，时间轴只选择已有的 200 帧（每帧对应 state[2*j]），不伪装成实时数据。原始数据及来源说明放在 public/data/mujoco-pointer，实时仿真仍使用既有本地服务。

**Tech Stack:** Astro / Starlight、原生视频与 SVG、Python / NumPy 数据导出；无新前端依赖。
